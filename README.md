# SkillPath AI

SkillPath AI is a multi-career skill-gap-to-job intelligence platform. Users build a free-form profile, see personalized job matches, identify missing skills, and receive a learning roadmap for the selected career path.

The existing dark career-intelligence UI is implemented as a React and Vite single-page app backed by a FastAPI service. The platform supports engineering, technology, business, finance, healthcare, HR, marketing, design, and research careers rather than assuming every user is a software developer.

## Supported career domains

The curated catalog includes roles across:

- Software/IT
- AI/Data
- Electrical Engineering
- Electronics and VLSI
- Mechanical Engineering
- Civil Engineering
- Chemical Engineering
- MBA/Management
- Finance and Accounting
- Marketing
- HR
- Healthcare
- Design
- Research and related professional paths

## Core workflow

1. Create or edit a profile with education, location, experience, target role, skills, and career interests.
2. Add unlimited free-form tags such as `VLSI & Digital Design`, `Power Systems`, or `Financial Analysis`.
3. Analyze the current profile to rank the complete job catalog.
4. Review matched and missing skills for the selected job.
5. Follow domain-aware courses and the time-to-ready roadmap.
6. Use the AI Assistant and Agent Activity views for explanations and workflow status.

Skills and career interests are independent tag lists. Spaces remain part of a phrase, comma or Enter commits a tag, and each saved tag has an individual remove button. Editing the profile invalidates stale analysis so the next analysis uses the current profile.

## Matching model

Every job is scored against the current profile using:

```text
final_score =
		skill_score * 0.40 +
		semantic_score * 0.40 +
		location_score * 0.10 +
		interest_score * 0.10
```

Sentence-Transformers provides semantic similarity when available. A deterministic lexical fallback keeps the app usable in lightweight environments. Scores are generated by the matching engine; the LLM is used for explanations and assistant responses, not numerical scoring.

## Run locally

### Backend

```powershell
cd backend
python -m pip install -r requirements.txt
$env:PYTHONPATH='.'
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

### Frontend

In a separate terminal:

```powershell
cd frontend
npm install
npm run dev
```

Vite may choose another available port if `5173` is busy. Set `VITE_API_URL` when the backend is running on a different port:

```powershell
$env:VITE_API_URL='http://127.0.0.1:8001/api'
npm run dev -- --host 127.0.0.1 --port 5176
```

The demo works without `OPENAI_API_KEY`. LangGraph is used when installed, with a compatible deterministic workflow fallback otherwise.

## API highlights

- `GET /api/health` - service status and catalog counts
- `POST /api/profile` - normalize and save a profile
- `POST /api/analyze` - analyze the exact submitted profile
- `GET /api/jobs` - return catalog jobs or profile-aware scored matches
- `GET /api/courses` - list learning resources, with optional `free_only=true`
- `GET /api/roadmap/{analysis_id}` - recalculate the selected learning roadmap
- `POST /api/assistant` - ask questions about the profile or analysis

## Validate the project

```powershell
cd backend
python -m pytest tests -q

cd ../frontend
npm run build
```

The backend tests cover multi-domain ranking, current-profile analysis, profile-aware job results, target selection, tag-safe profile parsing, and regression behavior for electronics, software, and finance profiles.
